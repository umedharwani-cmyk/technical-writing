# Google Docs Example

`sample-report.docx` is a short report I built to practise the features in the
main notes: heading styles, a numbered list, a bulleted list and a table.

## Open it in Google Docs

1. Upload `sample-report.docx` to Google Drive.
2. Right-click it, choose **Open with > Google Docs**.
3. Use **File > Save as Google Docs** to get an editable copy.

## Things to try on it

- **Table of contents:** put the cursor under the title, then
  **Insert > Table of contents**. It works because every section uses a real
  Heading style, not just bold text.
- **Comments and suggestions:** switch to *Suggesting* mode (top right) and edit
  a sentence, then accept or reject it.
- **Version history:** make a few edits, then **File > Version history >
  Name current version** and call it "Draft 1".
- **Equation:** **Insert > Equation**, then type `\frac{a}{b}` and press space.
- **Citation:** **Tools > Citations**, pick APA, add a source, insert it.
- **Export:** **File > Download > PDF**.
